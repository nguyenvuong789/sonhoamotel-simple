# Sơn Hoa Motel static page

Simple static HTML clone built from archived Sơn Hoa Motel content.

## Files

- `index.html` - landing page
- `styles.css` - responsive styling
- `assets/` - local images copied from archive

Open `index.html` directly in a browser or host the folder on GitHub Pages, Netlify, Vercel, or any static hosting.
